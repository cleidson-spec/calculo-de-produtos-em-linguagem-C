# calculo-de-produtos-em-linguagem-C
Desenvolvi um algoritmo de monitorização e análise de variação de preços de produtos da cesta básica utilizando lógica de programação no VisuAlg Web.  O objetivo do sistema é automatizar o cálculo da variação percentual entre dois períodos (mês anterior vs. mês atual) e classificar automaticamente a tendência de mercado de cada item.
